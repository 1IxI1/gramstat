NFT and jetton transfers, swaps, mints, and deposits are tracked using Toncenter actions. Newly launched protocols may not be supported yet. To check whether an action is included in these metrics, open it on tonscan.org. If it is recognized there, it is included in the statistics. If not, it is not.
